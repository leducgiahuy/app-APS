
# Flutter Agent Plugin

The official plugin for Dart and Flutter maintained by the Flutter team.

This plugin is designed to extend AI agent capabilities for Flutter development.
It bundles together skills, MCP server configuration, and rules to provide
tailored instructions to agents for common Dart and Flutter development
workflows. By giving the agent domain expertise, you drastically reduce mistakes
and ensure agents reliably complete tasks following best practices.
